What Is Next.js?

Understanding the full-stack React framework and its core capabilities.

Next.js App Router

The React Framework for the WebReact Framework សម្រាប់ Full-Stack Web

Next.js is an open-source React framework created by Vercel. While React is a library for building user interfaces, Next.js provides the full architecture needed for production: routing, rendering, backend actions, and optimization.Next.js គឺជា React framework បង្កើតឡើងដោយក្រុមហ៊ុន Vercel។ ខណៈពេលដែល React គឺជា UI Library, Next.js ផ្ដល់នូវរចនាសម្ព័ន្ធពេញលេញសម្រាប់ Production ដូចជា Routing, Rendering, Backend និង Optimization។

Official Definition: Next.js is a React framework for building full-stack web applications. You use React Components to build user interfaces, and Next.js for additional features and optimizations.និយមន័យផ្លូវការ៖ Next.js គឺជា React framework សម្រាប់បង្កើត full-stack web applications។ អ្នកប្រើ React ដើម្បីបង្កើត UI និងប្រើ Next.js សម្រាប់មុខងារ full-stack និងការបង្កើនល្បឿន។
Next.js Built-in Capabilities
  • File-System Routing: Folder-based pages, layouts, and nested routes
  • Server Components: Fast rendering with zero client-side JS bundle overhead
  • Server Actions: Type-safe asynchronous mutations directly from forms
  • Asset Optimization: Automatic WebP images, self-hosted fonts, scripts
  • Metadata & SEO: Dynamic Open Graph and search engine tags built-in

import { NextResponse } from "next/server";
import type { NextRequest } from "next/server";

export function middleware(request: NextRequest) {
  const sessionToken = request.cookies.get("session")?.value;
  const isDashboard = request.nextUrl.pathname.startsWith("/dashboard");

  // Protect private routes
  if (isDashboard && !sessionToken) {
    return NextResponse.redirect(new URL("/login", request.url));
  }

  return NextResponse.next();
}

export const config = {
  matcher: ["/dashboard/:path*"],
};
