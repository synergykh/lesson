SECTION 02 • ARCHITECTURE

Global Anycast Edge Network

How 330+ data centers deliver ultra-low latency and DDoS absorption

ANYCAST

What is Anycast Routing?

Under traditional Unicast, an IP address belongs to ONE specific physical computer. Under Anycast, the SAME IP address (e.g. 104.21.72.18) is broadcast simultaneously by routers in hundreds of cities worldwide.

User in Phnom Penh → BGP routes to Phnom Penh Edge
User in Tokyo → BGP routes to Tokyo Edge
User in Frankfurt → BGP routes to Frankfurt Edge

DDoS Absorption at Scale

When an attacker commands a botnet of 100,000 infected machines across the globe, the attack traffic does not hit a single server. Instead, it gets dispersed and swallowed locally at the nearest regional edge node.

Network capacity exceeding 280+ Tbps means volumetric attacks are filtered before reaching origin pipes.

SECTION 06 • SAFETY WARNING

CRITICAL: Review Existing DNS First

Why updating nameservers without auditing DNS can take down your company

DANGER ZONE

The Automatic Scan Fallacy

When you add a domain, Cloudflare queries common record names (like www, mail, api). It CANNOT find non-standard subdomains (e.g. staging-auth-internal.taskflow.com) or private TXT records.

If an existing record is missing when you switch nameservers, that service INSTANTLY ceases to exist for the entire world.

What Commonly Breaks

  • Corporate Email: Missing MX records cause bounced emails globally.
  • Email Deliverability: Missing SPF/DKIM TXT records marks mail as spam.
  • Third-Party SaaS: Google Search Console, Postmark, Stripe verification.
  • Internal Microservices: Private APIs and staging servers break.
SECTION 07 • NAMESERVERS

Nameservers Explained

Authoritative nameservers vs Recursive resolvers and delegation

CONCEPTS

Recursive Resolver (e.g. 1.1.1.1 or ISP)

The "detective" DNS server your browser contacts. It doesn't own any records; its job is to traverse the root servers and TLD servers to discover who holds the authoritative answers.

Client → Asks Resolver: "What is taskflow.com?"
Resolver → Asks Root (.) → Asks .com TLD → Reaches Cloudflare

Authoritative Nameserver (Cloudflare)

The ultimate source of truth. Holds the actual DNS database records for taskflow.com. Whatever Cloudflare nameservers publish is the official answer given to the recursive resolver.

Cloudflare Nameserver answers:
"taskflow.com points to 104.21.72.18 with TTL 300s"

SECTION 11 • REVERSE PROXY

Understanding Reverse Proxies

How Cloudflare terminates connections and shields origin IP addresses

ARCHITECTURE

Forward Proxy vs Reverse Proxy

Forward Proxy: Sits in front of clients (e.g. corporate VPN). Hides client identities from destination servers.

Reverse Proxy: Sits in front of origin servers. Clients think they are communicating directly with the origin, but are actually talking to Cloudflare.

Origin Shielding

Because TCP handshakes terminate at Cloudflare's edge, malicious port scans (Nmap) and direct SYN floods hit Cloudflare's massive infrastructure instead of exhausting your server's RAM or bandwidth.

Client IP ──> [Cloudflare Edge (TLS Termination)] ──> [Origin Server]

When requests are proxied, your Nginx or Node.js server sees the incoming TCP connection originating from a Cloudflare IP (e.g. 172.70.x.x), NOT the visitor's real IP.

What is a Content Delivery Network (CDN)?

Bringing static content closer to users worldwide to slash latency

CDN

The Speed of Light Constraint

Data traveling over fiber optics takes time. A round-trip packet from Southeast Asia to a Virginia server takes ~220ms minimum. Adding TLS handshakes and multiple asset requests means page load times exceed 3+ seconds.

By caching images (WebP/AVIF), CSS bundles, JavaScript scripts, and fonts on edge SSDs in 330+ cities, requests are answered in 10–25ms without ever touching your origin server.

SECTION 13 • HTTP HEADERS

Cache-Control Headers & Edge TTL

Mastering max-age, s-maxage, public, private, and stale-while-revalidate

SPECIFICATION

Essential Directives

public: Can be cached by browser AND CDN edge.
private: Only user browser may cache (never CDN).
max-age=3600: Cache in browser for 1 hour.
s-maxage=86400: Cache in Cloudflare CDN for 24h.
stale-while-revalidate: Serve stale while fetching fresh in background.

Production Example: Static Bundles

SECTION 13 • CRITICAL SAFETY

Caching Dynamic vs Static Content

Never cache authenticated user sessions, cookies, or sensitive API payloads

DATA LEAK RISK

The Catastrophic Data Leak Scenario

If you configure Cloudflare Cache Rules with "Cache Everything" on /api/user/profile or pages with a Set-Cookie header, User A's private dashboard and session token will be cached at the edge and served to User B!

Golden Caching Rules

  • Always include Cache-Control: private, no-store on authenticated endpoints.
  • Cloudflare automatically bypasses cache if it detects Set-Cookie unless explicitly overridden.
  • Cache HTML pages only if they are completely public and static.

SECTION 15 • SSL MODES

Cloudflare SSL / TLS Modes Explained

Off, Flexible, Full, and Full (Strict) architectural comparison

SSL MODES

SECTION 15 • PITFALL

Why Flexible SSL is Dangerous

Preventing Man-In-The-Middle attacks between Cloudflare and your origin

AVOID FLEXIBLE

Problem 1: Infinite Redirect Loops

In Flexible mode, Cloudflare forwards traffic to origin on port 80 (HTTP). If your origin has an Nginx rule: return 301 https://$host$request_uri;, Nginx sends redirect back to browser. Cloudflare repeats on port 80. Result: ERR_TOO_MANY_REDIRECTS.

Problem 2: Man-In-The-Middle Snooping

Data travels unencrypted over the open internet between Cloudflare edge and your cloud provider. Anyone between Cloudflare and your origin can extract database credentials and auth cookies.

SECTION 17 • DDOS MITIGATION

DDoS Protection at Edge Scale

Volumetric floods (SYN, UDP) and Layer 7 HTTP application attacks

DEFENSE

Layer 3 & Layer 4 Attacks (Volumetric)

Attacks like SYN floods, UDP amplification, and NTP reflection aim to overwhelm network bandwidth. Cloudflare's autonomous DDoS engine scrubs these packets in real-time at the edge router level using XDP and eBPF.

Layer 7 Attacks (HTTP Floods)

Attackers send valid HTTP GET/POST requests targeting expensive backend queries (e.g. database search). Cloudflare detects abnormal request rates and challenges suspicious clients via Turnstile.

SECTION 18 • WAF ACTIONS

WAF Rule Actions & Threat Detection

Choosing between Allow, Managed Challenge (Turnstile), and Block

ACTIONS
ALLOW / SKIP

Explicitly bypasses other security checks. Use for trusted partner webhook IPs (e.g. Stripe, GitHub).

MANAGED CHALLENGE

Shows an invisible or one-click Cloudflare Turnstile challenge. Genuine humans pass seamlessly; automated bots fail.

BLOCK

Returns an immediate HTTP 403 Forbidden with a branded error page. Drops payload before reaching origin.

  • MX: Points to mail servers (Google, Proton, Outlook). Must be DNS ONLY!
  • SPF (TXT): Defines which server IPs can send email for your domain.

SECTION 47 • DNSSEC

DNSSEC: Security & Migration Gotchas

Cryptographic validation of DNS records and how misconfigured DS records break resolution

DNSSEC

What DNSSEC Protects

DNS Security Extensions (DNSSEC) signs DNS responses with cryptographic keys (RRSIG). Prevents DNS spoofing / cache poisoning where hackers hijack traffic to fake servers.

The Migration Trap (SERVFAIL)

If DNSSEC is active at your registrar with your OLD DNS provider, changing nameservers to Cloudflare will cause DNS resolvers worldwide to fail verification and return SERVFAIL.

Migration rule: Delete old DS records at registrar → Switch nameservers → Wait 24h → Enable Cloudflare DNSSEC and add new DS record.

SECTION 52 • SSL TROUBLESHOOTING

Troubleshooting: SSL & Redirect Loops

Diagnosing ERR_TOO_MANY_REDIRECTS, pending certificates, and mixed content

SSL ERRORS
1. ERR_TOO_MANY_REDIRECTS

Cause: SSL mode is set to Flexible while origin redirects HTTP to HTTPS. Fix: Set mode to Full (Strict).

2. SSL Handshake Failed (525)

Cause: Cloudflare cannot complete TLS handshake with origin. Fix: Check origin port 443 is listening and TLSv1.2/1.3 enabled.

3. Mixed Content Warnings

Cause: HTTPS page loading images over http://. Fix: Enable Automatic HTTPS Rewrites in Cloudflare.
